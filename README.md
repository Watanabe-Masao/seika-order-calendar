# 青果 発注カレンダー（高知市中央卸売市場）

高知市中央卸売市場（青果）の休市日をもとに、**発注できる日**と**その日に何日分を発注するか**を表示するカレンダーです。
休市日データは GitHub Actions が毎週自動で取得し、GitHub Pages に公開します。

## しくみ

```
高知青果市場の公開Googleカレンダー（休市日・臨時開市日）
   │  毎週月曜 6:17 JST（GitHub Actions）
   ▼
scripts/build.py   ics を取得 → site/data/calendar.json
   │  変更があればコミット／翌年分が12月になっても無ければ Issue
   ▼
site/ を GitHub Pages に配置（index.html が calendar.json と order.js で計算・表示）
```

| パス | 内容 |
|---|---|
| `scripts/build.py` | ics の取得・解析、異常検知（件数が前回の5割未満なら更新しない） |
| `site/order.js` | 発注日の計算ロジック（ページ・購読カレンダー・テストで共用） |
| `scripts/feeds.mjs` | 購読用カレンダー `site/cal/seika.ics` を作成（デプロイ時に生成、コミットしない） |
| `site/index.html` | カレンダー表示（カレンダー／発注日一覧／設定） |
| `site/data/calendar.json` | 生成データ（自動更新） |
| `data/raw/*.ics` | 取得した元データ（差分確認用） |
| `data/status.json` | 最終確認日。28日ごとに更新し、60日無操作によるスケジュール停止を防ぐ |
| `docs/research.md` | 事前調査メモ |

## 発注ルール

- 発注した翌日に市場から納品される。翌日が休市の日は発注できない。
- 1回の発注で「納品日〜次の納品日の前日」までをまかなう。
  - 例：2027年8月は14〜16日と18日(水)が休市 → 13・14・15・17日は発注不可、12日に13〜16日の4日分。
- 休市日カレンダーにある日は、予定名に関係なく休市として扱う（予定名の表記は年によって変わるため）。
- ページの「設定」で次の2点を切り替えられる（端末ごとに保存）。
  - 市場が休みの日でも、翌日が開市なら発注できる（既定：オン）
  - 12/31 など「仲卸は営業」の日を開市として扱う（既定：オフ）

## カレンダーの取り込み（購読）

ページの「取り込み」タブから `cal/seika.ics`（1本）を登録します。すべて終日の予定で、期間は1年前〜休市日データの最終日です。

| 予定名の印 | 内容 | COLOR |
|---|---|---|
| 🟦 発注 1日分 | 1日分の発注日 | royalblue |
| 🟩 発注 2日分 | 2日分の発注日 | seagreen |
| 🟧 発注 n日分 | 3日分以上の発注日（nは実際の日数。例：🟧発注 4日分、🟧★発注 7日分） | darkorange |
| ⬜ 休市日 / ⬜★開市日 | 休市日、日・水の臨時開市日 | gray |

- 購読カレンダーは多くのアプリ（Google・iPhone）でカレンダー全体が1色になるため、予定名の先頭の印で見分ける。予定ごとの色（RFC 7986 COLOR）も入れてあり、対応アプリでは色も付く。
- ★：通常の週（日曜・水曜が休市）と違う日。発注日は「通常の週なら何日分か」と、その原因になった日を説明欄に記載。
- すべての予定の説明欄の末尾に、公開されている元のカレンダー（高知市 市場カレンダーのページ、高知青果市場のサイト）へのリンクを付ける。URL欄には市のページを入れる。
- 予定のIDは種類と日付で固定しているため、データが更新されても二重登録にならない。
- 既定のルール（休市日でも翌日が開市なら発注可、12/31は休み扱い）で作成。ページの「設定」は購読カレンダーには反映されない。

## LINE通知

`.github/workflows/notify.yml` が、対象の発注日について **前日 15:07** と **当日 7:07**（JST）の2回、LINE公式アカウントから友だち全員に配信する（ブロードキャスト）。対象は次のどちらかの発注日。

- 🟧 3日分以上のまとめ発注
- ★ 通常の週（日・水休み）と日数が違う発注日

発注できない日は個別に通知せず、通知の中に「発注ありません」「次回の発注」として書く。2027年の対象日は月0〜5日（配信は2回ずつなので月0〜10回）。

### 設定手順

1. [LINE Official Account Manager](https://manager.line.biz/) で公式アカウントを作成（無料のコミュニケーションプラン：月200通まで。友だち1人に1通で数える）
2. アカウントの「設定 → Messaging API」で Messaging API を有効にする（プロバイダーを作成）
3. [LINE Developers](https://developers.line.biz/console/) で、そのチャネルの「Messaging API設定 → チャネルアクセストークン（長期）」を発行
4. GitHub の Settings → Secrets and variables → Actions に `LINE_CHANNEL_ACCESS_TOKEN` として登録
5. Actions →「LINE通知」→ Run workflow（`when` を選び、`date` に `2027-08-12`、`dry_run` オン）で本文を確認 → `dry_run` オフで実際に届くか確認
6. 公式アカウントの友だち追加用QRコード・URLを配る

- トークン未設定のときは送信せずに終わる（失敗にはしない）。
- 同じ対象日・同じ本文は再実行しても二重送信しない（`X-Line-Retry-Key`）。
- GitHub のスケジュール実行は混雑時に数十分遅れることがある。

```sh
python3 -m unittest discover -s tests -v
node --test tests/*.test.mjs
python3 scripts/build.py --offline   # data/raw/*.ics から作り直す
node scripts/feeds.mjs               # site/cal/seika.ics を作成

python3 -m http.server -d site 8000  # http://localhost:8000
```

## 注意

- 元データは高知青果市場（青果卸）のカレンダーです。高知市の公式「市場カレンダー」（PDF）を正とし、年末年始など重要な日は照合してください。
- 翌年分は例年 10月中旬〜11月中旬に登録されます。
